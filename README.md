# Mining AI Copilot Dashboard Interactivo

Versión mejorada e interactiva para minería.

## Incluye
- Dashboard vertical con scroll.
- Botones funcionales por perfil.
- Tarjetas pequeñas para KPIs.
- Barras dinámicas de operación.
- Gráfico tipo donut de impacto.
- Producción, stock, contratos, downtime y costo por tonelada.
- Preguntas dinámicas por perfil:
  - Operacional
  - Mantenimiento
  - Financiero
  - Ejecutivo
  - Comercial
- Respuestas automáticas.
- Acciones sugeridas.
- Simuladores SAP ERP, MII, ME, CAP y BTP.
- Backend Python Flask.
- Archivos nube: Dockerfile, Procfile, render.yaml.

## Ejecutar
```bash
cd Mining_AI_Copilot_Dashboard_Interactivo
pip install -r requirements.txt
python app.py
```

Abrir `http://127.0.0.1:5000`
